# 🟡 AI Recruitment & Candidate Matching Agent — نظام التوظيف الذكي

> نظام AI متكامل لمطابقة المرشحين مع الوظائف باستخدام **Vector Search** و**RAG**.  
> يحلل السير الذاتية ويوصي بأفضل المرشحين أو الوظائف تلقائياً.

## التقنيات المستخدمة

| التقنية | الدور |
|---------|-------|
| **Pinecone Vector DB** | قاعدة بيانات متجهات — تخزين وبحث دلالي فائق السرعة |
| **OpenAI Embeddings** | تحويل نص CV أو الوظيفة إلى متجه رقمي |
| **Cohere Reranker** | إعادة ترتيب نتائج البحث للحصول على دقة أعلى |
| **OpenAI GPT-4** | تحليل نتائج البحث وكتابة توصيات مفصّلة |
| **RAG Pipeline** | Retrieval-Augmented Generation لنتائج مدعومة بالبيانات |

---

## ما يميّز هذا النظام

| الميزة | التفصيل |
|--------|---------|
| **Semantic Search** | يفهم معنى CV والوظيفة — لا مجرد keywords |
| **Reranking** | مرحلة ثانية للترتيب تزيد دقة النتائج بشكل كبير |
| **AI Recommendations** | يولّد تقرير مطابقة مكتوب بذكاء اصطناعي |
| **Scalable** | Pinecone يتعامل مع آلاف CVs بكفاءة |
