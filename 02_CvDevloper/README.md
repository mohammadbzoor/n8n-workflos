# 🟢 AI CV Assistant — مساعد السيرة الذاتية الذكي

> نظام ذكاء اصطناعي لمساعدة المستخدمين في إنشاء وتحسين سيرتهم الذاتية.  
> يعمل عبر **واجهة Chat** مدمجة في n8n.

## كيف يعمل

```
المستخدم (Chat UI)
        │
        ▼
┌─────────────────────────┐
│     AI CV Assistant     │
│   (n8n AI Agent Node)   │
└─────────────────────────┘
        │
   ┌────┴────┐
   ▼         ▼
OpenAI     أدوات
GPT-4     مساعدة
        │
        ▼

```

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|----------|
| **OpenAI GPT-4** | توليد وتحسين محتوى السيرة الذاتية |
| **n8n AI Agent** | إدارة المحادثة والاستجابة |
| **n8n Chat UI** | واجهة المحادثة مع المستخدم |
